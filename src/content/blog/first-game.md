This is my first -true- game, I made in the summer of my first year at Epitech, I did it after having followed the nice tutorials of Kris Luro from Unity 3D France.

You control a rocket through a 2D level, the camera is in third person. There is a key to propel the rocket, 2 key for the direction, and a boost which multiply the power of the rocket for few seconds. It may sound simple at first place but no one finished the last level as far as I know and only one the tutorial (on about a dozen people whom I shared it)... to bad for the learning curve :(.

The game only uses unity's primitive, for example the rocket is made of a sphere, a cylinder and 2 cubes, I didn't know modeling yet.

It's composed of 3 solo levels relatively long, the purpose is to go from point A to a point B, avoiding balls, lasers, flames, waterfalls, and, in the last levels, not being cached up by lava. I also added a multiplayer, only for 2 player connected in lan, on 3 map: one empty, one with a gravity 0 bubble in the middle, and one full of the solo's traps, the rocket has the ability to shoot starting from its top, in a straight line, the purpose is to kill the opponent, more than he kills us, either in shooting him or pushing him to crash.

This game is very addictive, so i I just took the concept for a new game, the source code can't be reused, the game is coded haphazardly, and it's a miracle it run without -too much- crash. so i started from scratch to make a game on this theme, this time with short and easy levels (at start), a proper multiplayer online, with a master server, and most important fully modeled, I talk more about it in a upcoming articles.

If you want to try it, it's still available on the page I have set up at this time *(that page is no longer online)*: you' ll find this game (on the 18 mo, there is 15 for the unbearable musics that you will stop immediately), a tiny fps from the unity3d france's tutorials and some buoyancy test (make an object to float) and a test of gameplay for a "star wars podracer" like game.
